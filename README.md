# Jacob Josh Tubo — Certificate & Engineering Portfolio

A modern, high-performance static portfolio website built for **GitHub Pages**.

## Key Features

- **Guaranteed GitHub Pages Compatibility**: Pure HTML5, CSS3, and Vanilla JavaScript with **zero build steps, zero dependencies, and zero deployment errors**.
- **Interactive 3D Tilt & Glare**: High-fidelity micro-interactions on certificate and skill cards.
- **Interactive SVG Systems Architecture**: Animated topology node graph in the Hero section showcasing hardware, software, and robotics connectivity.
- **Full Resolution Lightbox**: Click any certificate to inspect full credentials with keyboard (`Escape`, `Enter`) accessibility.
- **Responsive & Accessible**: Fully optimized for mobile, tablet, and desktop screens.

## Publishing to GitHub Pages

### Option 1: GitHub Pages via GitHub Actions (Recommended)
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. The included `.github/workflows/deploy.yml` will automatically publish the site.

### Option 2: GitHub Pages via Main Branch Root
1. Go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Click **Save**.
